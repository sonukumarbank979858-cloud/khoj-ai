# Khoj AI

A small Perplexity-style Android app: it searches the web with Tavily, then Gemini writes an answer with numbered sources.

## Use
1. Download `KhojAI.apk` from the latest Release and install it.
2. Open Settings in the app and add your Gemini API key (aistudio.google.com) and Tavily API key (app.tavily.com).
3. Ask anything.

The APK is built automatically by GitHub Actions on every push to `main`.
